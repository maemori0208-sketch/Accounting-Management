# 会計管理アプリ

自治会・町内会・PTA・サークルなど、**団体（組織）の会計**を管理するためのシンプルな Web アプリです。
ブラウザで開くだけで動作し、**インストール・アカウント登録・インターネット接続は不要**。
会費や支出の記録から、**決算報告書・出納帳の作成、Excel／PDF 出力**まで、これ 1 つで完結します。

- 🧾 収入・支出・振替の記帳と、口座残高の自動計算
- 🏦 現金・銀行・定期預金などの口座管理
- 📚 1 年度あたり **2 つの帳簿**（例：一般会計・特別会計）に対応
- 🔄 年度切り替えと**繰越金の自動計算**（前年度繰越 → 次年度繰越）
- 📊 ダッシュボード（サマリー・科目別支出の円グラフ）
- 📄 **決算報告書**（収支計算書形式・監査署名欄）と**出納帳**、**Excel(.xlsx) / 印刷・PDF** 出力
- 🌙 ダークモード／📱 スマホ対応（スワイプ操作・ホーム画面に追加）
- 💾 データはお使いの端末内に保存。**バックアップ／引き継ぎ**用の書き出し・読み込み

> データはクラウドではなく、**その端末のブラウザ内（localStorage）だけ**に保存されます。定期的なバックアップを推奨します。

## 主な機能

### ダッシュボード
- 選択中の年度・帳簿に連動した **前年度繰越／収入／支出／収支／次年度繰越** のサマリー。
- 口座別の「繰越（期首）→ 年度末残高」一覧。
- **科目別支出の円グラフ**（ドーナツ型・SVG 描画、上位 7 件＋「その他」に自動集約）。

### 取引
- **収入・支出・振替**を登録。日付・カテゴリ・金額・メモ・帳簿を指定。
- 一覧からの編集（✎）・削除（🗑）、期間・区分・口座・キーワードでの絞り込み。
- **CSV 出力**（Excel で開けます）。

### 口座
- 種別：**現金 / 銀行口座 / 定期預金 / その他**。帳簿ごとに管理。
- 期首残高を設定すると、以降の残高は取引から自動計算。
- 口座の**編集・削除**（削除時は関連取引もまとめて削除する確認あり）。

### 決算報告書（帳簿の作成）
- 2 種類を切り替えて作成：
  - **収支決算報告書**（収支計算書形式：前年度繰越＋収入−支出＝次年度繰越、科目別内訳、口座別残高）
  - **出納帳**（口座ごとに入金・出金・残高を時系列表示）
- 対象期間・**帳簿（帳簿1 / 帳簿2 / 合計）**・**定期預金の含む／除く**を選択可能。
- **監査向け機能**：収支計算の照合、監査確認の定型文＋署名・押印欄（監査人名は設定に保存）。
- 出力：**Excel(.xlsx)**（罫線あり・A4・数値セル）／**印刷・PDF 保存**。
- 掲載するセクション（サマリー・収支計算・収入支出・円グラフ・口座残高・署名欄）を個別にオン/オフ。

### 設定
- **団体（組織）管理**：複数の団体を切り替えて独立管理。
- **会計年度**：期首月（例：4 月）を設定。暦年（1 月始まり）にも対応。
- **帳簿名**：2 つの帳簿の名称を自由に変更（例：一般会計／特別会計）。
- **報告書の署名・監査設定**：監査人名・監査確認文言。
- **カテゴリ管理**：収入・支出カテゴリの追加・削除。
- **データ管理**：全データ／団体単位のバックアップ・読み込み、全データ削除。

### 操作性・表示
- **ダークモード**（右上のボタンで切替、設定は保存）。
- **スマホ対応**：レスポンシブ表示、画面の**左右スワイプで切替**、`❓` の操作ガイド。
- **PWA**：URL で公開すれば「ホーム画面に追加」でアプリのように起動、オフライン動作。

## 使い方（起動）

### パソコン（Windows / Mac）
1. `index.html` を保存します。
2. ファイルを**ダブルクリック**して既定のブラウザ（Edge・Chrome・Safari など）で開きます。
3. ブックマークしておくと次回すぐ開けます。

> パソコン 1 台で使う分には、ファイルを直接開くだけで問題なく動作します。

### ローカルサーバで動かす（任意）
`.claude/launch.json` に開発用サーバ設定が含まれています。`http-server` などで配信できます。

```bash
# 例：Node.js の http-server を使う場合（このフォルダで実行）
npx --yes http-server . -p 8199 -c-1
# → ブラウザで http://localhost:8199/ を開く
```

## スマホで使う・URL で公開する（推奨）

iPhone の Safari は**ローカルの HTML ファイルを直接開けない**仕様です（「HTML Viewer」系アプリは
**データが保存されず消える恐れ**があるため非推奨）。スマホで使う場合は、**URL で公開**してブラウザで開くのが確実です。

### 公開のしかた（無料でも可）
`index.html` ／ `manifest.webmanifest` ／ `sw.js` ／ `icon-512.png` の **4 ファイルを同じ場所**に置いて公開します。

- **Cloudflare Pages / Netlify** … フォルダをドラッグ＆ドロップするだけで URL が発行されます（手軽）。
- **GitHub Pages** … リポジトリに置いて Pages を有効化。
- **庁内サーバ / NAS** … 静的ファイルとして設置し、内部 URL で配布（外部公開不要）。

### 各端末での開き方
| 端末 | 手順 |
| --- | --- |
| **iPhone (Safari)** | URL を開く → 共有 → **ホーム画面に追加** → アイコンから起動 |
| **Android (Chrome)** | URL を開く → ⋮ → **ホーム画面に追加／インストール** → アイコンから起動 |
| **パソコン** | URL を開く → ブックマーク（配布ファイルを直接開いても可） |

一度アイコンから開いておけば、**オフラインでも起動**でき、データもその端末に残ります。

> 詳しい配布・利用手順は同梱の **`利用ガイド.html`**（印刷・PDF 配布用）をご利用ください。

## 基本の操作フロー

1. **設定** → 団体名と「期首月」を登録（必要なら帳簿名も変更）。
2. **口座** → 現金・銀行口座などを追加し、**期首残高**を入力。
3. **取引** → 収入・支出・振替を登録（残高は自動計算）。
4. **ダッシュボード** → 収支や繰越金、科目別支出を確認。
5. **決算報告書** → 期間・帳簿を選んで「作成」→ **印刷／PDF** または **Excel 出力**。

## データの保存・バックアップ・引き継ぎ

- データは**お使いの端末のブラウザ内（localStorage）**にのみ保存されます（自動同期・クラウド保存はありません）。
- **バックアップ**：設定 → データ管理 → 「全データをバックアップ」で JSON ファイルを保存。月 1 回など定期的に。
- **引き継ぎ・端末移行**：
  - **全体を移す**：片方で「全データをバックアップ」→ もう片方で「ファイルを読み込み」（**上書き復元**）。
  - **団体単位で渡す**：「現在の団体を書き出し」→ 読み込むと**新しい団体として追加**（既存データは残ります）。
- 旧バージョンのバックアップも読み込み可能（帳簿・報告書設定などは自動補完）。

> ⚠️ 端末やブラウザのデータを消去すると記録も消えます。**操作前・定期的なバックアップ**を強く推奨します。

## ファイル構成

```
会計管理アプリ/
├── index.html            … アプリ本体（HTML/CSS/JS 一体・自己完結）
├── manifest.webmanifest  … PWA 用マニフェスト（ホーム画面追加・アプリ名/アイコン）
├── sw.js                 … Service Worker（オフライン用キャッシュ）
├── icon-512.png          … アプリアイコン（¥ ロゴ）
├── 利用ガイド.html        … 配布・利用手順書（印刷/PDF 用、単体で開けます）
└── README.md             … このファイル
```

> **更新の反映**：`sw.js` は**ネットワーク優先**（開くたびに最新を取得し、オフライン時のみキャッシュを使用）です。GitHub Pages などへ公開し直すだけで、番号の更新なしに次回起動で新版が表示されます（現在 `kaikei-v4`）。
> ただし、**旧版（v3 以前）の Service Worker が入っている端末は、最初の 1 回だけ旧版が表示**されることがあります。その後は常に最新になります（すぐ切り替えたい場合は `Ctrl+F5`、または一度ブラウザのサイトデータを削除）。

## 技術情報

- **依存関係ゼロ**：フレームワーク・ビルド・外部 CDN なし。単一の `index.html` に HTML/CSS/JavaScript を同梱。
- **完全オフライン / 自己完結**：外部リソースを読み込まないため、社内ネットや電波の無い環境でも動作。
- **保存**：ブラウザの `localStorage`。
- **グラフ**：SVG を自前で描画（ライブラリ不使用）。
- **Excel 出力**：外部ライブラリを使わず、`.xlsx`（ZIP + XML）を自前で生成（罫線・A4 ページ設定・数値セル対応）。
- **PWA**：`manifest.webmanifest` ＋ `sw.js` によりインストール・オフライン対応（`https`／`localhost` で有効。`file://` では自動的にスキップ）。
